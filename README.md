# 🐳 Docker Compose 项目管理面板 (Windows)

> 一个轻量级的交互式菜单工具，帮你快速管理多个 Docker Compose 项目。  
> 无需安装 Python / Node，下载即用，适合 Windows + Docker Desktop 用户。

---

## ✨ 功能特性

- ✅ 自动递归扫描指定路径下的 `docker-compose.yml` / `docker-compose.yaml`
- ✅ 交互式菜单列出所有项目，支持启动（后台）、停止、查看状态、实时日志
- ✅ 首次运行引导选择搜索目录（支持盘符或任意文件夹），配置自动保存
- ✅ 随时按 `R` 键重新选择搜索路径，无需手动修改配置文件
- ✅ 自动检测并唤醒 Docker Desktop（如果未运行）
- ✅ 纯内存处理，不生成任何临时文件，性能高效

---

## 🖥️ 运行环境

- Windows 10 / 11（或 Windows Server 2016+）
- Docker Desktop 已安装并添加到 PATH
- **必须以管理员身份运行**（右键 → 以管理员身份运行）

---

## 🚀 快速开始

1. **下载** `超级升级版.bat` 到任意文件夹
2. **右键** 点击该文件 → **以管理员身份运行**
3. **首次运行**：脚本会自动检测可用盘符，你只需输入编号选择盘符，或选 `0` 手动输入完整路径（如 `D:\Projects\`）
4. 之后每次打开都会自动加载上次的路径，直接显示项目列表
5. 输入项目编号即可进行启动 / 停止 / 状态 / 日志等操作

---

## 🧭 操作说明

### 主菜单
- 输入数字选择项目，进入操作菜单
- 输入 `0` 退出脚本
- 输入 `R` 重新选择搜索路径

### 操作菜单
- `1` – 后台启动该项目（`docker compose up -d`）
- `2` – 停止该项目（`docker compose down`）
- `3` – 查看容器状态（`docker compose ps`）
- `4` – 查看实时日志（`docker compose logs -f --tail=50`，按 `Ctrl+C` 退出）
- `5` – 返回主菜单
- `R` – 重新选择搜索路径

---

## ⚠️ 注意事项

- **项目文件夹名称请不要包含感叹号 `!`**（这是 Windows 批处理的历史限制）
- 搜索路径支持根目录（如 `D:\`），脚本会自动递归查找所有子目录
- 如果未找到任何项目，可按 `R` 键重新选择路径
- 如需重置配置，只需手动删除脚本同目录下的 `config.ini` 文件

---

## 📁 文件说明

- `超级升级版.bat` – 主脚本
- `config.ini` – 自动生成，保存你上次输入的搜索路径（**请勿上传到 GitHub**）

## ❓ 常见问题

**Q: 启动时提示“Docker 未运行”？**  
A: 脚本会自动尝试打开 Docker Desktop，如果等待超时（30秒），请手动启动 Docker 后再试。

**Q: 为什么我选的盘符在菜单里没显示？**  
A: 脚本只检测“存在”的物理盘符。如果是虚拟盘或软驱（如 A:），请选 `0` 手动输入完整路径。

**Q: 我想修改黑名单（忽略某些目录）怎么办？**  
A: 打开脚本，找到 `set "IGNORE_LIST=tidb weaviate postgres redis"` 这一行，按空格分隔添加或删除关键词即可。

**Q: 为什么杀毒软件报毒？**  
A: 这是批处理文件申请管理员权限时的常见误报。源代码公开透明，你可以用记事本打开查看全部内容，确认无误后添加信任即可。
